## 麥克風與音訊檔案

SmeggTuner 在您的裝置上分析麥克風聲音，計算音高、簧片頻率和拍頻。在 Android 上，應用程式會請求麥克風權限。您可以在 Android 的應用程式設定中拒絕或撤銷此權限，之後將無法使用麥克風即時調音。開啟音訊檔案無需麥克風權限。

音訊分析在本機進行。SmeggTuner 不會將麥克風音訊、匯入的音訊檔案或調音測量資料上傳給開發者、分析服務或廣告服務。即時音訊儲存在記憶體中供分析使用，啟動調音器不會自動儲存麥克風錄音。在 Android 上，應用程式離開前景時會停止採集聲音和播放合成音。

選擇 WAV 檔案時，SmeggTuner 會讀取該檔案以便播放和分析。Android 的文件選擇器控制應用程式可存取的檔案。如果您選擇雲端儲存服務，該服務可能會按其作業方式將檔案下載到裝置。暫存本機副本可能會留在應用程式快取中，直到 Android 或您將其清除。

應用程式在本機儲存語言、主題、基準音高和音訊校正等偏好設定。本機資料庫也可能包含在具備相應功能的版本中儲存的調音工作記錄。

技術記錄檔可能包含應用程式錯誤、裝置或音訊裝置資訊、設定以及檔案路徑。記錄檔儲存在本機，包括 Android 系統記錄檔。應用程式不會自動上傳記錄檔，也不會向開發者傳送當機報告。如果您選擇傳送記錄檔或螢幕擷取畫面以取得支援，請先檢查內容，刪除不想分享的資訊。

Android 應用程式使用應用程式專用儲存空間，不會為本機資料庫或檔案額外加密。資料保護也取決於裝置的安全設定。應用程式已啟用 Android 備份和裝置間移轉功能。根據 Android 版本、裝置和備份設定，作業系統可能會將應用程式資料複製到您的備份服務或另一臺裝置。開發者不會收到這些備份。您可以透過裝置和備份服務管理備份。

## 網路連線、帳號與第三方

Android 調音器安裝後無需帳號或網際網路連線即可使用。應用程式不含廣告 SDK 或應用程式內分析追蹤工具，不提供帳號註冊，也不會自動上傳調音資料。它不請求存取您的聯絡人、位置、相機、照片庫或廣告辨識碼。選擇檔案僅授予應用程式存取所選文件的權限，不會開放整個儲存空間。

Android 版不會像桌面版那樣透過 GitHub 檢查更新。Google Play 根據 Google 的政策管理 Play 版的安裝和更新。Google 或裝置製造商可能會根據您的設定及其各自的政策，獨立處理與應用程式商店、作業系統、備份或診斷有關的資訊。

桌面版的更新檢查功能可選。啟用後，應用程式會透過 HTTPS 向 GitHub 提供應用程式名稱和版本以查詢新版本。GitHub 會收到包括 IP 位址在內的連線資訊。您可以在設定中關閉此功能。請求中不含音訊或調音檔案。

點選線上隱私權政策、網站或 GitHub 連結會開啟外部瀏覽器。本政策也可在應用程式內離線閱讀。支援信箱連結會開啟您的電子郵件應用程式，只有您選擇傳送時才會發出郵件。造訪外部網站時，目標網站會收到常規網路請求資訊，包括您的 IP 位址和瀏覽器資訊，並適用該網站自身的政策。捐助由連結所指向的服務提供者處理，SmeggTuner 不會收到您的付款卡資訊。如果所用版本支援匯出或列印文件，您選擇的目標位置或列印服務會收到該文件。

## 網站與瀏覽器版

造訪 smeggtuner.com 或載入瀏覽器版時，會向主機代管基礎設施傳送請求。連線和安全資訊可能包括 IP 位址、請求的網址、時間、瀏覽器資訊和錯誤。主機代管和資安服務提供者處理這些資訊以提供服務並防止濫用。Cloudflare 提供網站流量防護，其處理方式見 [Cloudflare 隱私權政策](https://www.cloudflare.com/privacypolicy/)。

啟用流量分析時，網站使用不使用 Cookie 的 Umami 統計功能。統計內容可能包括瀏覽的頁面、來源網站、瀏覽器和裝置類別、大致位置、帶統計標記的連結點選情況及頁面效能。Umami 處理連線資訊以區分不同的造訪紀錄。不使用 Cookie 並不意味著不處理任何資訊。分析資料的接收端透過本網站提供。這些網站統計獨立於 Android 應用程式，不包含麥克風音訊或調音測量資料。

網站將佈景主題偏好存入瀏覽器儲存空間，也可能使用 Cookie 儲存語言偏好。聯絡頁面使用 Cloudflare Turnstile 限制自動請求。它會處理瀏覽器和連線訊號，詳見 [Turnstile 隱私宣告](https://www.cloudflare.com/turnstile-privacy-policy/)。閱讀本隱私權政策無需完成聯絡頁面的驗證。

獲得瀏覽器授權後，瀏覽器版調音器會在瀏覽器內本機處理麥克風音訊，不會將音訊上傳以供分析。您可以透過瀏覽器的權限和網站儲存設定撤銷存取權限並清除本機偏好。
