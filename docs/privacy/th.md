## ข้อมูลที่เก็บไว้บนอุปกรณ์

แอปเก็บการตั้งค่าต่าง ๆ เช่น ภาษา ธีม ระดับเสียงอ้างอิง และการสอบเทียบเสียงไว้ในเครื่อง ฐานข้อมูลในเครื่องยังอาจมีงานตั้งเสียงที่บันทึกไว้จากรุ่นที่รองรับฟังก์ชันดังกล่าว

บันทึกเหตุการณ์ทางเทคนิคอาจมีข้อผิดพลาดของแอป รายละเอียดของเครื่องหรืออุปกรณ์เสียง การตั้งค่า และพาธของไฟล์ บันทึกเหตุการณ์จะเก็บไว้ในเครื่อง รวมถึงบันทึกระบบของ Android แอปจะไม่อัปโหลดบันทึกเหล่านี้โดยอัตโนมัติ และไม่ส่งรายงานการขัดข้องให้ผู้พัฒนา หากเลือกส่งบันทึกเหตุการณ์หรือภาพหน้าจอเพื่อขอความช่วยเหลือ โปรดตรวจสอบก่อนและนำข้อมูลที่ไม่ต้องการเปิดเผยออก

แอป Android ใช้พื้นที่จัดเก็บส่วนตัวของแอป โดยไม่ได้เพิ่มชั้นการเข้ารหัสให้ฐานข้อมูลหรือไฟล์ในเครื่อง การป้องกันข้อมูลยังขึ้นอยู่กับการตั้งค่าความปลอดภัยของอุปกรณ์ด้วย แอปเปิดใช้การสำรองข้อมูลของ Android และการถ่ายโอนระหว่างอุปกรณ์ ระบบปฏิบัติการอาจคัดลอกข้อมูลแอปไปยังผู้ให้บริการสำรองข้อมูลหรืออุปกรณ์อีกเครื่อง ขึ้นอยู่กับเวอร์ชัน Android อุปกรณ์ และการตั้งค่าสำรองข้อมูล ผู้พัฒนาไม่ได้รับข้อมูลสำรองเหล่านั้น คุณจัดการข้อมูลสำรองได้ผ่านอุปกรณ์และผู้ให้บริการสำรองข้อมูลของคุณ

## การเชื่อมต่อเครือข่าย บัญชี และบุคคลที่สาม

เมื่อติดตั้งแล้ว เครื่องตั้งเสียงบน Android ใช้งานได้โดยไม่ต้องมีบัญชีหรือเชื่อมต่ออินเทอร์เน็ต ไม่มี SDK โฆษณา เครื่องมือติดตามเพื่อวิเคราะห์การใช้งานในแอป ระบบลงทะเบียนบัญชี หรือการอัปโหลดข้อมูลการตั้งเสียงอัตโนมัติ แอปไม่ขอเข้าถึงรายชื่อผู้ติดต่อ ตำแหน่ง กล้อง คลังภาพ หรือตัวระบุโฆษณา เมื่อเลือกไฟล์ คุณให้สิทธิ์เข้าถึงเฉพาะเอกสารที่เลือก ไม่ใช่พื้นที่จัดเก็บทั้งหมด

รุ่น Android ไม่ตรวจสอบการอัปเดตผ่าน GitHub เหมือนรุ่นเดสก์ท็อป Google Play จัดการการติดตั้งและการอัปเดตรุ่นที่เผยแพร่ผ่าน Play ตามนโยบายของ Google ทาง Google หรือผู้ผลิตอุปกรณ์อาจประมวลผลข้อมูลเกี่ยวกับร้านค้า ระบบปฏิบัติการ การสำรองข้อมูล หรือการวินิจฉัยแยกต่างหาก ตามการตั้งค่าของคุณและนโยบายของผู้ให้บริการแต่ละราย

บนเดสก์ท็อป หากเปิดใช้ตัวตรวจสอบการอัปเดต แอปจะติดต่อ GitHub ผ่าน HTTPS โดยส่งชื่อและเวอร์ชันของแอปเพื่อค้นหารุ่นใหม่ GitHub จะได้รับข้อมูลการเชื่อมต่อ เช่น ที่อยู่ IP ของคุณ คุณปิดการตรวจสอบนี้ได้ในการตั้งค่า คำขอนี้ไม่มีไฟล์เสียงหรือไฟล์งานตั้งเสียง

หากเลือกลิงก์ไปยังนโยบายฉบับออนไลน์ เว็บไซต์ หรือ GitHub ลิงก์จะเปิดในเบราว์เซอร์ภายนอก คุณอ่านนโยบายนี้ในแอปได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ลิงก์อีเมลสำหรับขอความช่วยเหลือจะเปิดแอปอีเมล ข้อความจะถูกส่งเมื่อคุณเลือกส่งเองเท่านั้น เว็บไซต์ปลายทางจะได้รับข้อมูลคำขอเว็บตามปกติ รวมถึงที่อยู่ IP และรายละเอียดเบราว์เซอร์ และใช้นโยบายของเว็บไซต์นั้น ผู้ให้บริการที่ลิงก์ไปเป็นผู้ดำเนินการเรื่องเงินบริจาค SmeggTuner ไม่ได้รับรายละเอียดบัตรชำระเงินของคุณ หากรุ่นที่ใช้รองรับการส่งออกหรือพิมพ์เอกสาร ปลายทางหรือบริการพิมพ์ที่คุณเลือกจะได้รับเอกสารนั้น

## เว็บไซต์และรุ่นเบราว์เซอร์

การเข้า smeggtuner.com หรือโหลดรุ่นเบราว์เซอร์จะส่งคำขอไปยังระบบโฮสติ้ง ข้อมูลการเชื่อมต่อและความปลอดภัยอาจรวมถึงที่อยู่ IP, URL ที่ขอ เวลา ข้อมูลเบราว์เซอร์ และข้อผิดพลาด ผู้ให้บริการโฮสติ้งและความปลอดภัยประมวลผลข้อมูลนี้เพื่อให้บริการและป้องกันการใช้งานในทางที่ผิด Cloudflare ให้บริการปกป้องการรับส่งข้อมูลเว็บ ดูวิธีประมวลผลได้ใน[นโยบายความเป็นส่วนตัวของ Cloudflare](https://www.cloudflare.com/privacypolicy/)

เมื่อเปิดใช้การวิเคราะห์ เว็บไซต์จะใช้ Umami เก็บสถิติโดยไม่ใช้คุกกี้ สถิติอาจรวมถึงหน้าที่เข้าชม เว็บไซต์ต้นทางที่ส่งผู้ใช้มา ประเภทของเบราว์เซอร์และอุปกรณ์ ตำแหน่งโดยประมาณ การคลิกลิงก์ที่ติดแท็ก และประสิทธิภาพของหน้าเว็บ Umami ประมวลผลข้อมูลการเชื่อมต่อเพื่อแยกการเข้าชมแต่ละครั้ง การไม่ใช้คุกกี้ไม่ได้หมายความว่าไม่มีการประมวลผลข้อมูล จุดรับข้อมูลสถิติให้บริการผ่านเว็บไซต์นี้ สถิติเหล่านี้แยกจากแอป Android และไม่มีเสียงจากไมโครโฟนหรือค่าที่วัดในการตั้งเสียง

เว็บไซต์เก็บธีมที่คุณเลือกไว้ในพื้นที่จัดเก็บของเบราว์เซอร์ และอาจใช้คุกกี้เพื่อจดจำภาษาที่เลือก หน้าติดต่อใช้ Cloudflare Turnstile เพื่อจำกัดคำขออัตโนมัติ โดยประมวลผลสัญญาณจากเบราว์เซอร์และการเชื่อมต่อตามที่ระบุใน[ประกาศความเป็นส่วนตัวของ Turnstile](https://www.cloudflare.com/turnstile-privacy-policy/) คุณอ่านนโยบายความเป็นส่วนตัวนี้ได้โดยไม่ต้องผ่านการตรวจสอบในหน้าติดต่อ

เมื่อได้รับอนุญาตให้ใช้ไมโครโฟน เครื่องตั้งเสียงรุ่นเบราว์เซอร์จะประมวลผลเสียงภายในเบราว์เซอร์บนเครื่องของคุณ โดยไม่อัปโหลดเสียงนั้นไปวิเคราะห์ คุณใช้การตั้งค่าสิทธิ์และพื้นที่จัดเก็บของเว็บไซต์ในเบราว์เซอร์เพื่อเพิกถอนสิทธิ์และล้างการตั้งค่าที่เก็บในเครื่องได้

## การขอความช่วยเหลือ ระยะเวลาเก็บรักษา และการลบ

หากคุณติดต่อผู้พัฒนา ข้อมูลที่คุณเลือกส่ง ที่อยู่อีเมล และข้อความที่ติดต่อกันจะใช้เพื่อตอบคำขอและตรวจสอบปัญหาที่แจ้ง อย่าส่งเสียงที่บันทึก ข้อมูลส่วนบุคคล หรือเอกสารที่มีข้อมูลอ่อนไหว เว้นแต่จำเป็นต่อการจัดการคำขอ ข้อมูลจะไม่ถูกขายหรือนำไปใช้โฆษณาแบบเจาะจงกลุ่มเป้าหมาย

การตั้งค่าและงานที่บันทึกไว้จะอยู่ในเครื่องจนกว่าคุณจะลบ ล้างพื้นที่จัดเก็บของแอป หรือถอนการติดตั้ง บน Android ให้ไปที่ การตั้งค่า > แอป > SmeggTuner > พื้นที่จัดเก็บ > ล้างพื้นที่จัดเก็บ เพื่อรีเซ็ตข้อมูลแอป ชื่อเมนูอาจแตกต่างกันตามอุปกรณ์ การล้างแคชจะลบไฟล์ชั่วคราว แต่ไม่ได้รีเซ็ตการตั้งค่าทั้งหมด การถอนการติดตั้งหรือล้างข้อมูลแอปจะไม่ลบไฟล์ที่คุณส่งออกไปที่อื่น สำเนาที่ส่งให้ผู้อื่น หรือข้อมูลสำรองที่บริการอื่นเก็บไว้ โปรดจัดการสำเนาเหล่านั้นแยกต่างหาก

ข้อความที่ใช้ติดต่อขอความช่วยเหลือจะเก็บไว้นานเท่าที่จำเป็นเพื่อตอบคำขอ ติดตามปัญหา หรือปฏิบัติตามหน้าที่ตามกฎหมายที่เกี่ยวข้อง บันทึกการทำงานและความปลอดภัยของเว็บไซต์เก็บไว้เพื่อดำเนินบริการ ป้องกันและตรวจสอบการใช้งานในทางที่ผิด ส่วนสถิติการเข้าชมเก็บไว้เพื่อทำความเข้าใจและปรับปรุงเว็บไซต์ ระยะเวลาเก็บรักษาขึ้นอยู่กับวัตถุประสงค์เหล่านี้และการตั้งค่าบริการที่เกี่ยวข้อง คุณสอบถามหรือขอให้ลบข้อมูลที่ผู้พัฒนาเก็บไว้ได้ทางช่องทางติดต่อด้านความเป็นส่วนตัวข้างต้น ผู้พัฒนาไม่สามารถเข้าถึงหรือลบไฟล์ที่มีอยู่เฉพาะในอุปกรณ์ของคุณจากระยะไกล

## ทางเลือกและสิทธิของคุณ

ในกรณีที่กฎหมายคุ้มครองข้อมูลมีผลใช้บังคับ คุณอาจมีสิทธิเข้าถึง แก้ไข หรือลบข้อมูลส่วนบุคคลของคุณ จำกัดหรือคัดค้านการประมวลผล และรับสำเนาข้อมูลในรูปแบบที่โอนย้ายได้ คุณยังอาจร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลในพื้นที่ได้ หากต้องการใช้สิทธิ โปรดติดต่อผู้พัฒนา อาจจำเป็นต้องยืนยันตัวตนเพื่อป้องกันการเปิดเผยข้อมูลแก่บุคคลอื่น

การประมวลผลที่จำเป็นต่อการให้บริการเว็บไซต์ การรักษาความปลอดภัยของเว็บไซต์ หรือการตอบคำขอ อาศัยวัตถุประสงค์ของบริการที่เกี่ยวข้องและประโยชน์โดยชอบด้วยกฎหมายเท่าที่กฎหมายอนุญาต อาจมีการเก็บข้อมูลเพื่อปฏิบัติตามหน้าที่ตามกฎหมายด้วย ผู้ให้บริการอาจประมวลผลข้อมูลในประเทศอื่นตามข้อกำหนดและมาตรการคุ้มครองที่ใช้กับบริการของตน แอปไม่ได้สร้างบัญชี จึงไม่มีบัญชี SmeggTuner ที่ต้องลบ
