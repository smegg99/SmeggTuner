## マイクと音声ファイル

SmeggTuner はマイクの音声から、音高、リードの周波数、うなりを端末上で計算します。Android ではマイクの使用許可を求めます。Android のアプリ設定で許可を拒否または取り消すことができます。その場合、マイクを使ったリアルタイム調律は利用できなくなります。音声ファイルを開くのにマイクの許可は必要ありません。

音声は端末内で解析します。SmeggTuner がマイクの音声、読み込んだ音声ファイル、調律の測定値を開発者、解析サービス、広告サービスに送信することはありません。リアルタイムの音声は解析用にメモリーに保持されます。チューナーを起動してもマイクの録音が自動保存されることはありません。Android ではアプリがフォアグラウンドを離れると、音声の取り込みと合成音の出力が停止します。

WAV ファイルを選ぶと、SmeggTuner はそのファイルを再生と解析のために読み取ります。アプリがアクセスできるファイルは Android のドキュメント選択画面で決まります。選んだクラウドストレージの提供元が、その提供元の運用に従ってファイルを端末にダウンロードする場合があります。端末内の一時コピーは、Android または利用者が削除するまでアプリのキャッシュに残ることがあります。

## 端末に保存する情報

アプリは言語、テーマ、基準ピッチ、音声の校正などの設定を端末内に保存します。端末内のデータベースには、調律作業の保存に対応した版で保存した作業内容が含まれる場合もあります。

技術ログには、アプリのエラー、端末やオーディオデバイスの詳細、設定、ファイルパスが含まれる場合があります。Android のシステムログを含め、ログは端末内に保存されます。アプリがログを自動でアップロードしたり、開発者にクラッシュレポートを送ったりすることはありません。サポートのためにログやスクリーンショットを送る場合は、先に内容を確認し、共有したくない情報を取り除いてください。

Android アプリはアプリ専用ストレージを使います。端末内のデータベースやファイルをアプリが追加で暗号化することはなく、保護の程度は端末のセキュリティ設定にも左右されます。Android のバックアップと端末間の転送は有効です。Android のバージョン、端末、バックアップ設定によっては、OS がアプリのデータをバックアップサービスや別の端末にコピーすることがあります。開発者がそのバックアップを受け取ることはありません。端末とバックアップサービスの設定から管理できます。

## ネットワーク接続、アカウント、第三者

Android 版のチューナーはインストール後、アカウントもインターネット接続も必要としません。広告 SDK、アプリ内の利用状況を追跡するツール、アカウント登録、調律データの自動アップロード機能はありません。連絡先、位置情報、カメラ、写真ライブラリ、広告識別子へのアクセスは要求しません。ファイルを選ぶと、ストレージ全体ではなく、選んだドキュメントへのアクセスが許可されます。

Android 版は、デスクトップ版が行う GitHub での更新確認を行いません。Google Play 版のインストールと更新は、Google のポリシーに従って Google Play が管理します。Google または端末メーカーは、利用者の設定とそれぞれのポリシーに従い、ストア、OS、バックアップ、診断に関する情報を独自に処理する場合があります。

デスクトップの任意の更新確認機能は、新しいリリースを探すために HTTPS で GitHub に接続し、アプリ名とバージョンを伝えます。GitHub は IP アドレスなどの接続情報を受け取ります。更新確認は設定で無効にできます。このリクエストに音声や調律ファイルは含まれません。

オンラインのポリシー、ウェブサイト、GitHub へのリンクを選ぶと外部ブラウザーが開きます。本ポリシーは接続がなくてもアプリ内で読めます。サポートのメールリンクはメールアプリを開きます。実際にメールを送るのは利用者が送信を選んだときだけです。リンク先のサイトは、IP アドレスやブラウザーの詳細を含む通常のウェブリクエスト情報を受け取り、独自のポリシーを適用します。寄付の手続きはリンク先の事業者が行い、SmeggTuner が決済カードの詳細を受け取ることはありません。ドキュメントの書き出しや印刷に対応する版では、選んだ出力先または印刷サービスがそのドキュメントを受け取ります。

## ウェブサイトとブラウザー版

smeggtuner.com にアクセスしたりブラウザー版を読み込んだりすると、ホスティング基盤にリクエストが送られます。接続・セキュリティ情報には、IP アドレス、要求した URL、時刻、ブラウザー情報、エラーが含まれる場合があります。ホスティング事業者とセキュリティ事業者は、サービスの提供と不正利用の防止のためにこの情報を処理します。ウェブ通信は Cloudflare が保護しています。その取り扱いは [Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご覧ください。

ウェブサイトはアクセス解析が有効なとき、Cookie を使わない Umami の統計機能を利用します。対象には、訪問したページ、参照元サイト、ブラウザーと端末の種類、おおよその地域、タグ付きリンクのクリック、ページのパフォーマンスが含まれる場合があります。Umami は訪問を区別するため接続情報を処理します。Cookie を使わなくても情報の処理は行われます。解析データの送信先はこのサイトを通じて提供されます。このウェブサイトの統計は Android アプリとは別のもので、マイクの音声や調律の測定値は含まれません。

サイトはテーマ設定をブラウザーのストレージに保存し、言語設定の保存に Cookie を使う場合があります。お問い合わせページは、自動リクエストを制限するために Cloudflare Turnstile を使用します。ブラウザーと接続に関する信号の取り扱いについては、[Turnstile のプライバシーに関する説明](https://www.cloudflare.com/turnstile-privacy-policy/)をご覧ください。本ポリシーを読むためにお問い合わせページの認証を完了する必要はありません。

ブラウザー版のチューナーはマイクの使用許可を得た後、ブラウザー内で音声を処理します。解析のためにその音声をアップロードすることはありません。ブラウザーの権限設定とサイトデータの管理機能で、許可の取り消しや端末内の設定の削除ができます。
